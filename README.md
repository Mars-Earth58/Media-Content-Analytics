# Media Content Analytics Pipeline

A data analytics pipeline built in Python to extract, clean, and analyze a dataset of over 8,000 streaming media titles, uncovering trends in content production and distribution formats.

**Technologies Used:** Python, Pandas, SQL (Planned).

## Key Insights Discovered (Phase 1)
By running exploratory data analysis (EDA) on the media catalog, this Python script identified the following trends:

*   **Format Dominance:** The platform leans heavily toward feature-length content, with **6,126 Movies** compared to **2,674 TV Shows**.
*   **Production Trends:** Peak content volume occurred in **2018 (1,147 titles)**, with a noticeable decline in new releases leading into 2020 and 2021, likely reflecting shifts in global production schedules.

## Project Status
* **Phase 1 (Completed):** Data ingestion, null-value cleaning, and basic EDA using Pandas.
* **Phase 2 (In Progress):** Integrating a SQL database to run advanced querying and connecting the output to Tableau for visual dashboards.
