# Helpdesk Ticket Automation (Python + CSV)

## Overview
This beginner-friendly project simulates a simple helpdesk workflow using CSV data. It reads ticket records, summarizes counts per issue type (Hardware, Software, M365, Networking), calculates average resolution times for resolved tickets, and exports a bar chart visualization. It demonstrates practical skills aligned with helpdesk operations, M365 administration, and basic automation.

## What this demonstrates
- Service desk thinking: issue categorization, status tracking, resolution time
- Simple automation: reading and processing data with Python
- Reporting: console summary + chart (`ticket_summary.png`)

## Files
- `tickets.csv` — sample ticket data
- `ticket_analysis.py` — analysis script
- `ticket_summary.png` — generated chart
- `README.md` — project guide
